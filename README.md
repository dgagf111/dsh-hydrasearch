# dsh-hydrasearch

给 DeepSeek Harness 加上两个免费、几乎不限量的网页搜索后端。

装好之后，DSH 内置的 `web_search` / `web_fetch` 背后就多了一层保障：TinyFish 与 AnySearch 两个后端轮流待命，一个不行自动换另一个。兼容 DSH 0.1.6-alpha.2 与 0.1.7-rc.1。

## 优势

- **都免费，频率限制极高。** TinyFish 与 AnySearch 都提供免费额度，日常搜索与抓取基本用不完。AnySearch 甚至不必先申请 key，匿名即可使用（只是额度低一些）。
- **双后端自动故障切换。** 某个后端超时、限流或出错，自动切到下一个，搜索不会因为一个后端的问题而整体失败。

## 免费额度与限流

| 后端 | 费用 | 限流 |
| --- | --- | --- |
| TinyFish 搜索 | 免费，不消耗账户余额 | 30 次/分钟 · 500 次/小时 |
| TinyFish 抓取 | 免费，不消耗账户余额 | 150 个网址/分钟 · 1000 个网址/天 |
| AnySearch（已填 key） | 免费档 1000 次/天 | 20 QPS |
| AnySearch（匿名） | 共用每日免费额度 | 按客户端 IP 限流，低于上者 |

TinyFish 的搜索与抓取在任何账户余额下都免费，余额为 0 也照常工作。AnySearch 不填 key 也能用，填 key 后升到免费档。数据来自两家官网，可能调整，以官网为准。

## 功能

- **搜索**：网页搜索，可按语言、地区、时间范围、站点黑白名单、垂直领域筛选，并控制每次翻几页。
- **抓取**：把指定网址抓成 Markdown、HTML 或 JSON，可选同时带出页面内的链接与图片链接。

## 安装

一条命令添加本仓库，然后重启 DSH：`dsh plugin --profile web add github:dgagf111/dsh-hydrasearch`

重启后打开 **插件页 → 已安装 → `dsh-hydrasearch` → 行内配置入口**。首次使用需要在卡片里给 TinyFish 填一个 key；AnySearch 可以先不填。

## 配置

全部在插件页的 `dsh-hydrasearch` 卡片里完成：

- **后端顺序**：拖动调整，排在前面的先用。
- **故障切换**：默认开启；关闭后只使用第一个可用的后端，它的失败就是最终结果。
- **后端参数**：搜索地址、语言、地区、时间范围、站点过滤、翻页数、抓取格式、超时、缓存策略等，按需填写，留空即不发送。

## API Key 与隐私

- **key 只存在你自己机器上的凭据中心**（DSH 的本地凭据文件），不上传、不同步、不写进日志。
- 插件只把 key 放进请求头，发给**你所调用的那个搜索服务本身**，除此之外没有任何第三方接收方；插件自身也不包含遥测或使用统计上报。
- 读取、写入、清除三个动作指向同一个存储位置。
